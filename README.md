## Project Title

Smart Home Automation using ESP32, IoT and Sinric Pro

## About the Project

This project is a Smart Home Automation system using ESP32, IoT and Sinric Pro.
It allows users to control home appliances remotely using a smartphone or voice commands.

## Features

- Control home appliances remotely
- Voice control using smart assistant
- ESP32-based system
- IoT-enabled appliance control
- Multiple relay control
- Easy and user-friendly operation

## Components Used

- ESP32
- Relay Module
- Switches
- Home Appliances / LEDs
- Wi-Fi
- Sinric Pro
- Jumper Wires
- Power Supply

## Software Used

- Arduino IDE
- Sinric Pro
- C/C++

## Working Principle

The ESP32 connects to Wi-Fi and Sinric Pro.
When the user gives a command through the mobile application or voice assistant,
Sinric Pro sends the command to the ESP32.
The ESP32 processes the command and controls the relay.
The relay switches the connected home appliance ON or OFF.

## Applications

- Smart homes
- Home appliance control
- IoT-based automation
- Voice-controlled devices
